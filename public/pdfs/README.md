# Urdu9866 PDF library

PDF paths are defined in `src/syllabus.ts` and follow this structure:

`/pdfs/section-{number}/part-{number}/{author}/{work}.pdf`

The included files are lightweight placeholders so every viewer route works in the prototype. Replace each placeholder with the corresponding syllabus PDF while keeping the same filename, or update its `pdf` value in `src/syllabus.ts`.
